## Frontend notes

- The `@/*` import alias points to this folder's root.
- `LayoutProps` and other route types are generated by `next typegen`, and `pnpm typecheck` runs it first. Run plain `tsc` only after typegen.
- Tailwind v4 has no config file. Theme tokens are defined in `app/globals.css`, including project tokens such as `bg-surface`, `bg-info`, `text-secondary-text` and `text-placeholder`. Reuse these instead of raw colors.
- Prettier sorts Tailwind classes, including inside `cn` and `cva`, so run `pnpm format` rather than ordering them by hand.
